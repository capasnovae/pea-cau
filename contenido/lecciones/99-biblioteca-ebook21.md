## idea: Acceso y problemas con libros

Se entra a eBook21 con el usuario y contraseña institucional, eligiendo un recurso. Si no entra a ninguna plataforma, recupera la contraseña institucional. Si entra a las demás pero no a eBook21, derivás "Blanqueo de Contraseña E-Book". Si entra pero un libro no abre ni descarga, que pruebe desde el proveedor; si sigue, "Inconvenientes E-Book21". No se deriva si el libro es solo físico, está restringido, el préstamo venció o anda desde el proveedor.

clave: Sin acceso solo a eBook21 → blanqueo. Libro que falla → probar el proveedor.
ejemplo: Santiago entra a Canvas sin problemas, pero no a eBook21.

## probalo 1

## idea: Pedir un libro y el libre deuda

Si el libro no está en el catálogo físico ni digital, derivás "Solicitud de libro" con título, autor, edición o ISBN y el motivo; no garantiza que se incorpore. El libre deuda de biblioteca se genera solo al pedir el visado. Si no se generó, el estudiante lo pide por correo a Biblioteca o derivás "Baja administrativa por deuda en Biblioteca"; tarda alrededor de una semana.

clave: Libro faltante → "Solicitud de libro". Libre deuda: automático con el visado.
