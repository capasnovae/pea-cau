# Base de conocimiento del CAU (kb-cau.21.edu.ar)

Copia de las páginas de la sección **Servicios CAU** de la base de conocimiento interna, exportada por la dueña el 2026-11-19.
Es material de **fuente** para las lecciones de PEA: lo que se escriba a partir de acá lleva la fuente y queda "A validar"
(la base puede tener datos de otro año, como las colaciones 2026). No es contenido para mostrar tal cual.

Quedaron afuera, por no ser del trabajo del asesor de un CAU de grado y pregrado (EDH, ED y PD):
las portadas de sección (Académico, Recursos, Herramientas, Trámites, Administrativo), el índice de derivaciones
(se exportó vacío), Posgrado, APLV (Programas de Aprendizaje para la Vida), Centro de Profesores Virtuales,
Reserva de quincho / SUM y el número de registro de la Universidad (un dato suelto).

Secundarias (programas para estudiantes, a confirmar si van): 05 Destacados 21, 18 Experiencias 21, 20 Ayudantía docente.
